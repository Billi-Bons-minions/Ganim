# Examples

Open these projects with *File → Open* (or `manim-studio examples/<file>.msproj`).
None of them needs LaTeX.

| File | What it shows |
|---|---|
| `circle-to-square.msproj` | The quickstart: a circle appears, turns into a square, a text is written |
| `function-analysis.msproj` | Zeros and extrema of a function; a parameter that moves a point along a graph |
| `geometry.msproj` | Pythagorean theorem; conic sections as implicit curves with a parameter |
| `graph-theory.msproj` | A network whose path from A to F is highlighted step by step |
| `linear-map.msproj` | A shear (2×2 matrix) applied to the coordinate grid and the basis vectors |
| `coupled-objects.msproj` | A label that follows a moving dot, and a dot whose position comes from a formula `(2.5 + 2 cos(w), 2 sin(w))` |
| `3d-and-fields.msproj` | 3D solids with a camera move; a vector field with stream lines |

`plugins/` contains an example extension (a dot grid, a style and a scene template). Copy it into the extensions folder (*Extensions → Manage extensions … → Open folder*) and enable it there.

The projects are generated by `tools/make_examples.py`.
